# 調査報告：新書レーベルは本当に違うのか

調査日：2026-10-23〜24（第一調査）、2026-10-25（再調査。指示書は ../brief-resurvey.md）
状態：Phase 2（調査・分析）の成果。研究版は未承認
詳細な集計は [analysis.md](analysis.md)、方法は [methodology.md](methodology.md)、主張と根拠の対応は [claims.md](claims.md)、出典は [sources.md](sources.md)

## 中心的な問い

世間で語られるレーベルのイメージは、実際の出版傾向と一致するのか

再調査では、この問いに答える前提として、主要な新書レーベル全体（一般向け・科学・ジュニア・ビジネス・実用・分野特化など）の個性・共通性・差異を明らかにする

## 結論（要約）

1. **新書全体では分野の多様性は大きい。ただし差の多くは、シリーズの性格（区分）の違いで説明できる**
   - 2016〜2025年に刊行のある76シリーズで、シリーズと分野（NDC 第1次区分）の関連は V = 0.25。一般向け49シリーズだけ（0.14）より大きい
   - シリーズの違いがもつ情報のうち 41% は区分（科学・分野特化・実用など）の違いによる。区分が違えば分野が違うのは当然で、それ自体は発見ではない
   - 2016〜2025年の対象シリーズの刊行点数の81%は一般向けのシリーズで、刊行点数の大部分は分野の構成が似たシリーズが占める（刊行点数の割合で、書店の棚や在庫の割合ではない）。シリーズが分かったときに分野の不確かさが減るのは全体で 10.5%
2. **一般向けのシリーズは、分野ではよく似ている（第一調査の結論は一般向けの中で維持）**
   - 一般向け49シリーズの V = 0.14。追加したシリーズを含めても、第一調査の29シリーズ（0.13）と同じ水準
   - 似てきたのは最近のことで、一般向けの違いは 1970年代（V = 0.33）から 2000年代以降（0.13〜0.15）に小さくなった
3. **際立つのは、分野を絞ったシリーズ**
   - 交通新聞社新書（運輸 70%）、ヨベル新書（キリスト教 84%）、健康人新書（医学 97%）、歴史新書y（歴史・地理 74%）、ブルーバックス（自然科学 78%）、ヤマケイ新書（登山などスポーツ 48%）
   - これらは同じ区分のシリーズにも似ていない（最も近いシリーズが同じ区分なのは、一般向け以外では 22 のうち 2）。「科学」「分野特化」といった区分ではなく、扱う分野そのものが個性になっている
4. **「歴史に強い」は、比率と点数で答えが違う**
   - 比率：歴史新書y 74%、じっぴコンパクト新書 42%、潮新書 37% などが中公新書（31%）より高い
   - 点数：歴史・地理の本を最も多く出しているのは中公新書（年17.3点）。一般向けの大きいシリーズの中では比率も最も高い
   - 中公新書の「歴史に強い」は、点数と一般向けの中での比率の両方で支持される
5. **一般向けの中の違いは、分野より書き手と売れ方に現れる（第一調査の結論を維持）**
   - 研究者・大学教員の著者（照合できた中で）：中公新書 83%、岩波新書 73%、ちくま新書 71% / 新潮新書 32%、SB新書 29%、ポプラ新書 22%
   - トーハン年間ベストセラー上位10点（2016〜2025年、100枠）：新潮新書 21、中公新書 10、幻冬舎新書・文春新書 9。岩波新書 0
6. **同じ出版社の複数のシリーズは、読者で分けるか、分野で分けるかの2通り**
   - 読者で分ける（分野は近い）：ちくま新書とちくまプリマー新書、岩波新書と岩波ジュニア新書、講談社現代新書と講談社+α新書、中公新書と中公新書ラクレ
   - 分野で分ける（分野が遠い）：講談社現代新書とブルーバックス、SB新書とサイエンス・アイ新書、PHP新書と PHPビジネス新書
7. **イメージは、刊行データで確かめられるものについては多くが当たっている**
   - 一致：中公新書の「歴史に強い」「学術的」、岩波・ちくまの「学術的」（著者の職業という代理指標で）、新潮新書の「大衆向け」、ブルーバックスの「科学」
   - 一致しない：岩波新書・講談社現代新書の「分野が幅広い」（幅広さは一般向け全体に共通）、PHP新書の「ビジネス」（ビジネスは PHPビジネス新書）
   - 検証できない：政治的な傾向、読みやすさ、読者層
   - 分野特化・実用のシリーズは、読者のイメージを述べた記述を見つけられなかった。出版社の説明（交通新聞社新書、岩波ジュニア新書など）と刊行データは一致する

中心的な問いへの答え：**「イメージは、データで確かめられる範囲では多くが当たっている。ただし一般向けのレーベルどうしの違いは分野ではなく書き手と売れ方にあり、分野ではっきり違うのは、分野を絞った専門のレーベルである」**

## 主な発見

### 1. 全シリーズの分野の違い（主分析）

- 76シリーズで V = 0.25、一般向け49シリーズで 0.14、区分の間（8区分）で 0.17（analysis.md「A」）
- 分野の構成の距離の中央値：全組み合わせ 0.41、一般向けどうし 0.31、区分が違う組み合わせ 0.55
- 他のシリーズから最も離れているのは、健康人新書、交通新聞社新書、新典社新書、ヨベル新書、ニュートン超図解新書、ブルーバックス。最も平均的なのは朝日新書、扶桑社新書、SB新書
- 一般向けで目立つのは星海社新書（芸術・スポーツ 30%。漫画・ゲームなどの区分）、日経プレミアシリーズ（社会科学 59%）、WAC BUNKO（社会科学 63%、政治 24%）、中公新書・潮新書（歴史・地理 31%・37%）

### 2. 特化：比率と点数

| 分野 | 比率が高いシリーズ | 点数が多いシリーズ（年平均） |
| --- | --- | --- |
| 歴史・地理 | 歴史新書y 74%、サンエイ新書 46%、じっぴコンパクト新書 42% | 中公新書 17.3、歴史新書y 15.8、ちくま新書 11.9 |
| 医学 | 健康人新書 97%、青春新書PLAY BOOKS 34% | 健康人新書 8.8、ブルーバックス 6.5、光文社新書 6.0 |
| 経済 | 日経文庫 57%、PHPビジネス新書 50% | 日経文庫 9.0、日経プレミアシリーズ 7.2 |
| 政治 | WAC BUNKO 24%、詩想社新書 23%、産経セレクト 20% | 中公新書 6.9、集英社新書 6.0、ちくま新書 5.8 |
| 運輸 | 交通新聞社新書 70% | 交通新聞社新書 7.3 |

- 比率の高いシリーズは点数の少ない分野特化・実用のシリーズ、点数の多いシリーズは一般向けの大きいシリーズであることが多い
- NDC の自然科学（4類）には医学が入る。健康の実用書が多いシリーズも「自然科学」に数えられるため、科学のシリーズとは綱（2桁）で区別した

### 3. 区分ごとの比較（追加分析）

- 一般向け：分野は似ている（V = 0.14）。違いは著者と売れ方
- 科学（4）：ブルーバックスとニュートン超図解新書は自然科学 78%・86%。ニュートン新書は翻訳 97%（海外の科学書の翻訳）、ページ 340、本体 1,400円で性格が違う
- ジュニア（2）：分野が最も分散している（集中度 0.14・0.19）。ちくまプリマー新書は疑問形の書名が 18% で全シリーズの最高
- ビジネス（3）：経済が 50〜57%、著者は実務家・経営者が多い（PHPビジネス新書 61%）
- 実用（6）：書名が長く（中央値15字）、強調の語（「すごい」「9割」など）が多い。中身は健康・雑学・自己啓発とシリーズで違う
- 分野特化（8）：互いに最も離れている（距離の中央値 0.87）
- 自費出版（3）：幻冬舎ルネッサンス新書の分野は一般向けに近い。著者を Wikidata で照合できた割合が 7〜9% と低い

### 4. 時代による変化

- 一般向けのシリーズの違い（V）：1950年代 0.21、1970年代 0.33、1990年代 0.19、2000年代以降 0.13〜0.15
- 岩波新書は1940年代に自然科学が27%あったが2020年代は5%で、社会科学が43%に増えた（第一調査）
- 新書全体でタイトルは長くなり（中央値5字→10字）、2000年代以降に疑問形・数字・強調の表現が増えた（第一調査）

### 6. 著者・売れ方・価格・ページ数

- 研究者の割合が高いのは、中公新書・岩波新書・ちくま新書に加え、追加したシリーズのヨベル新書 90%、ニュートン超図解新書 81%、歴史新書y 78%、ブルーバックス 75%
- ジャーナリストが多い：産経セレクト 38%、文春新書 24%、交通新聞社新書 23%
- ベストセラー：一般向け以外で入ったのは ちくまプリマー新書・青春新書PLAY BOOKS の各1回。詩想社新書が3回（2021〜2023年）
- 本体価格の中央値は一般向け 880円、科学・分野特化 1,000円。最も安いのは新潮新書 780円、最も高いのはニュートン新書 1,400円
- ページ数の中央値は一般向け 234、実用 197

## 第一調査からの変化

### 対象を増やしたことによる変化

- 分野の違いの大きさ：全シリーズの V は 0.25（第一調査は一般向けの 0.13 だけを出していた）。第一調査の「分野構成による違いは小さい」は一般向けに限った結論で、全シリーズには当てはまらない
- 年間刊行点数の最多の年：第一調査は一般向けで2018年（1,165点）だったが、2010〜2015年頃に終刊したシリーズ（角川SSC新書、アスキー新書、マイコミ新書など）を加えると、一般向けで2009年（1,371点）、全シリーズで2011年（1,800点）。最多の年は対象の範囲で変わるため、動画では「2000年代後半〜2010年代前半が多い」程度にとどめる
- 新しく分かった特徴：分野特化のシリーズの際立ち方、比率と点数の違い（歴史・医学・政治）、同じ出版社のシリーズの分け方、一般向けが2000年代以降に似てきたこと、ニュートン新書の翻訳の多さ
- 一般向けの中の結論（V、最も近い組み合わせ、著者の割合）は、同じ29シリーズで計算すると第一調査と同じ値（V = 0.129、講談社現代新書とちくま新書 0.078）

### データの取得・処理を直したことによる変化

| 修正 | 影響 |
| --- | --- |
| 教育社歴史新書の検索条件が洋泉社の「歴史新書」「歴史新書y」も含んでいた | 第一調査の横断比較の教育社歴史新書 85点（歴史 74%）は洋泉社のもの。歴史新書y として分けた |
| 番号が PI- の書誌（シリーズ名に INTELLIGENCE がない）を取り落としていた | 青春新書インテリジェンスの刊行点数 496 → 628。主に 2009〜2012年。横断比較（2016〜2025年）の点数は変わらない |
| マイクロ資料しかない戦中・戦後の本を「複製」として除いていた | 紙の書誌がない78件を残すよう変更（ラジオ新書 49、岩波新書 12、アテネ新書 9 など）。2016〜2025年の分析には影響しない |
| 古い本の ISBN が10桁でベストセラーと照合できていなかった | 中公新書 9→10、新潮新書 20→21 |
| Wikidata への問い合わせを再実行した | 第一調査のシリーズの著者の割合はほぼ同じ（平凡社新書が 57.0% → 56.7%） |

### 維持できる知見

- 中公新書の歴史（31%、1960年代から一貫）、研究者の著者の割合の順序、新潮新書のベストセラーへの集中、岩波新書の自然科学の減少、タイトルの変化、価格・ページ数の傾向

### 判断できない項目

- 政治的な傾向・読みやすさ・読者層（書誌にない）
- 参考文献・索引の掲載率（書誌から判定できない）
- 分野特化・実用のシリーズについての読者のイメージ（記述が見つからない）
- 翻訳書の著者の職業（文庫クセジュ、ニュートン新書。原著者名がローマ字で照合できない）

## 分析の限界と未確認事項

- **対象の網羅**：国立国会図書館の書誌の「新書」を含むシリーズ名と、Wikipedia の一覧から集めた。名前に「新書」を含まず、一覧にも載らないシリーズは漏れている可能性がある。1970-01-01 の書誌（出版年だけの古い本がこの日付に集まり500件を超える）は発見の検索で取得できなかった
- **規模の下限**：累計50件未満（刊行中は年5件未満）のシリーズは集めていない。サイエンス・パレット（38件）、淡交新書（37件）などは基準を下げれば対象になる
- **区分**：出版社の説明と名前から決めた。実用・分野特化・一般の境界は判断を含む（例：KAWADE夢新書、じっぴコンパクト新書を実用とした）
- **分野**：NDC は本の主題を1つに代表させる。自然科学（4類）に医学が入るなど、第1次区分は大まかで、綱（2桁）で補った
- **点数の少ないシリーズ**：期間内20点未満の9シリーズは距離の計算から除いた。20〜100点のシリーズの構成比はぶれやすい（表の stable）
- **著者の職業**：照合率 47.4%、シリーズで 0〜79%。Wikidata の現在の記述で、執筆時点の職業とは限らない。最初の著者だけを見ている
- **網羅**：国立国会図書館の所蔵（紙の本）に基づく。電子書籍は含まない。番号のない古い書誌が多いシリーズは、重版のまとめ方の誤差が残る
- **価格**：書誌の記載価格（表示価格を本体とみなし、税込は税率で戻した）
- **判型**：書誌の大きさ（cm）の標本（最大20件）で確かめた。全点ではない
- **販売実績**：公開されている年間上位10点だけ
- **イメージ**：11の情報源（個人の印象と明記するものが多い）。分野特化・実用のシリーズについての記述は見つからなかった。出版社の説明を確認できたのは9シリーズ

## 動画の構成の候補（修正版）

第一調査の推奨「分野は似ている。違うのは書き手と売れ方」は、一般向けに限った結論だった。全シリーズの結果から改めて選ぶ

### 中心的な問いと結論の候補

| 案 | 結論の一文 | 合う視聴者 |
| --- | --- | --- |
| A（推奨） | 刊行点数の8割は分野の似た一般向けのレーベルで、違いは書き手と売れ方。分野ではっきり違うのは、分野を絞った専門のレーベル | 新書をよく読む人。一般向けのイメージから入り、専門レーベルで広げる |
| B | 新書は「何の本か」より「誰に向けた本か」でレーベルが分かれる（同じ出版社のレーベルの分け方から入る） | 出版・編集に関心がある人 |
| C | 新書レーベルの地図：137レーベルを分野の近さで並べると、一般向けの大きな塊と、周りに散らばる専門レーベル | データの可視化に関心がある人 |

### 推奨案 A の流れ

1. 導入：新書のイメージ（ネット上の記述）と、137シリーズ・57,000点を集めたこと
2. 全体の地図：一般向けのシリーズは分野の構成が似ていて1つの塊になる。科学・鉄道・宗教・健康などの専門レーベルが周りに離れて並ぶ
3. 一般向けは本当に似ているか：分野では似ている（講談社現代新書とちくま新書はほぼ同じ構成）。1970年代はもっと違っていた
4. それでも中公新書の歴史は本物：比率（一般向けで最高）と点数（全シリーズで最多）の両方。比率だけなら専門レーベルの方が高い
5. 違いは書き手と売れ方：研究者の割合（中公・岩波・ちくま）とベストセラー（新潮）
6. 同じ出版社のレーベルの使い分け：読者で分ける（ちくま・岩波）か、分野で分ける（講談社のブルーバックス）か
7. 結論：イメージはデータで確かめられる範囲では多くが当たる。ただし政治色・読みやすさは確かめられない
