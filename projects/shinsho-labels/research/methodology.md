## 予備調査（Phase 1）の結論

### 先行コンテンツ

| 資料 | 方法 | 結論 |
| --- | --- | --- |
| note「新書レーベルを図解してみた ver.1」（2025-12-15） | 本人の経験による2軸の図。データなし（「独断と偏見＆経験則でまとめました」） | 定量調査ではない |
| ブログ「徹底解説！新書のレーベルごとの特徴まとめ」（2021-10-17、2026-07-11更新） | 8レーベルの印象（「印象論ですが」） | 定量調査ではない |
| 出版科学研究所「08年の新書刊行状況は」 | 2026-10-23 はメンテナンス中で読めなかった | 未確認 |
| YouTube 三宅書店「…新書診断…」 | 題名以外を取得できなかった（字幕・説明なし） | 未確認 |

- 確認できた範囲では、複数のレーベルを同じ指標で全件比較した調査は見つからなかった。網羅的な検索ではないため「存在しない」とは言えない
- 確認できなかった2件は、動画化の前に再確認する

### 対象の候補

- 指示書の初期候補に、Wikipedia「新書レーベル一覧」（2024-09-09 版、197行）から教養・一般向けの現行シリーズと、歴史的に大きい終刊シリーズを加えた60件（`data/label_candidates.csv`）
- Wikipedia は候補を見つけるためだけに使い、件数・刊行年は国立国会図書館の書誌で確認する
- 専門分野の小規模シリーズ（郷土本、業界団体の新書など）とノベルス・実用書の新書判（漫画・小説）は対象外とした（教養新書との比較の目的に合わないため）

### 書誌データの取得可能性（`data/label_survey.csv`）

- 国立国会図書館サーチ OpenSearch の題名検索（title=シリーズ名）は、書誌のシリーズ名にも一致する
- 候補ごとに最初の500件を調べ、シリーズ名（dcndl:seriesTitle）がそのシリーズのものである割合を確認した
  - 大半のシリーズで 97〜100%
  - 表記の違い：「ワニブックス|PLUS|新書」「紀伊国屋新書」「青春新書INTELLIGENCE」など。シリーズ名の正規表現で吸収する
  - 題名検索が他のシリーズにも一致するもの：「中公新書」（中公新書ラクレ）、「潮新書」（新潮新書）。シリーズ名で区別する
  - 同じ名前の別シリーズ：角川新書（1950年代の旧シリーズと 2014年以降）、河出新書（1950年代と 2018年以降）。刊行年で分ける
- 1回の検索で取得できるのは500件まで（501件目以降は取得できない。外部提供インタフェース仕様書 第1.5版）。10年ごとに検索し、500件を超える期間は年・月・日に分ける（`tools/research/ndl.py`）。月で分けた年は、年の件数と月の合計の差を「取りこぼしの可能性」として記録する

### データの利用条件

| 情報源 | 利用条件 | 使い方 |
| --- | --- | --- |
| 国立国会図書館サーチ（国立国会図書館作成の書誌） | 利用目的を問わず自由に利用できる（CC BY 互換）。API を使ったことを明記する | 書誌データの主な情報源。出典に「国立国会図書館サーチ（API を利用）」と書く |
| Wikidata | CC0 | 著者の職業（P106）・所属（P108）。名前と生年で照合する |
| トーハン年間ベストセラー（PDF） | 「トーハン調べ」と明示。営利目的の第三者への二次利用を禁止 | 新書ノンフィクションの上位10点の出現数を集計し、出典を明示する。ランキングの表そのものは配布しない（Git 管理外） |
| openBD | 「本の販促・紹介目的に限り」。API v1 は提供終了が告知されている | 使わない |
| ネット上の投稿・記事 | 引用の範囲で使う | 短い引用と出典の記録だけを残す |

## 刊行点数の数え方

- 書誌レコード数をそのまま刊行点数にしない
- 単位：シリーズの番号（「岩波新書 新赤版 ; 2026」の 2026）。同じシリーズで同じ番号の書誌は1点とする（重版・刷の違い）
  - 改版で番号が変わったものは別の1点（新しい刊行として扱う）
  - 番号のない書誌は、題名と著者で同じものを1点にまとめ、件数を記録する
- 紙の本だけを数える（国立国会図書館の所蔵資料。電子書籍は別のデータ提供元）
- 刊行年は書誌の出版年（dcterms:issued）。重版の書誌は、同じ番号の最も早い年を刊行年とする

## 期間

- 歴史分析：創刊から2026年10月時点の書誌まで
- 横断比較：2016〜2025年の10年間に刊行されたもの。この期間に刊行が続いていないシリーズは別に集計する

## 判定の規則（Phase 2 で決定）

### 刊行点数へのまとめ方（scripts/normalize.py）

- マイクロ資料・デジタル化資料だけの書誌は除外する
- 番号のある書誌：同じシリーズ・時期・番号を1点にまとめる
- 番号のない書誌：正規化した題名・最初の著者・版の表示（改版・新版など）が同じものを、同じ時期の中で1点にまとめる。同じ題名・著者の番号つきの点があればそこへまとめる
  - 版の表示を含めないと、改訂版を別の刊行として数えられない（日経文庫で 1,805 → 1,220 点に過剰にまとまった）
  - 時期をまたいでまとめない（岩波新書の新赤版が1969年の刊行になった）
- 時期：岩波新書は赤版・青版・黄版・新赤版、角川新書は旧（〜1960年代）と 2014年以降、河出新書は旧と 2018年以降
- ページ数：「209,3p」は本文 209・別立て 3。前付けが大きい書誌（「xii,209p」など）もあるため、大きい方を本文とする

### 分析の指標（scripts/analyze.py、stats.py、authors.py）

- 分野：NDC10 → NDC9 → NDC8 → 版不明の順に採用し、第1次区分で集計する
- 価格：表示価格（税の記載なし）は本体価格とみなす。「税込」は刊行年月の税率で本体価格に直す。実質価格は消費者物価指数（総合、2020年=100、e-Stat）で換算
- 著者：最初の著者を Wikidata のラベル・別名と生年（書誌の生年がある場合）で照合する。職業の区分の優先順は 研究者・大学教員 → ジャーナリスト → 実務家・経営者 → 作家・評論家 → その他
  - 照合率が低いシリーズは、照合できなかった著者を全員研究者・全員研究者以外とした上下限を示す
- ベストセラー：トーハンの PDF から新書ノンフィクション上位10点を抽出し、ISBN で titles.csv と照合する。PDF の配置が崩れた年は scripts/bestsellers.py の OVERRIDES で補う（2022年4位）
- ネット上のイメージ：記述を読んで記録し、キーワードの規則でカテゴリに分ける。否定（「〜には向いていない」など）は別のカテゴリにする

### 使えなかった指標

- 参考文献・索引の掲載率：別立てページ（「209,3p」の 3）の有無を代わりにしようとしたが、中公新書で 0% になるなど出版社の書誌の付け方の違いを反映するだけだったため使わない。未検証として扱う
- 政治的な傾向・読者層・読みやすさ：書誌に情報がない

## 国立国会図書館 API の注意

- until に年だけ（YYYY）を渡すとその年の1月1日と解釈される（岩波新書の2005年が 60件ではなく 6件になった）。期間は必ず YYYY-MM-DD で指定する（tools/research/tests/test_ndl.py）

## 再実行

```sh
cd projects/shinsho-labels/research
python3 scripts/survey_labels.py      # 予備調査（任意）
python3 scripts/collect.py            # 書誌の取得（cache/ndl/ の保存済みの応答を使う。--offline で問い合わせない）
python3 scripts/normalize.py          # 刊行点数へのまとめ → data/titles.csv
python3 scripts/analyze.py            # 集計
python3 scripts/stats.py              # 分野の比較の統計量
python3 scripts/authors.py            # Wikidata の照合（cache/wikidata/ を使う）
python3 scripts/author_shares.py
python3 scripts/bestsellers.py        # トーハンの PDF（cache/shinsho-labels/bestsellers/）から表を作る（cache に出力）
python3 scripts/bestseller_labels.py
python3 scripts/code_images.py        # イメージの分類
```

- 実行環境：Python 3.12（リポジトリの .venv）。bestsellers.py は pymupdf 1.28.2 が必要。それ以外は標準ライブラリだけ
- 2026-10-24 に cache の保存済みの応答から全工程を再実行し、data/ の出力が一致することを確認した
- 応答を保存していない状態から取得し直すと、国立国会図書館・Wikidata の更新で件数が変わることがある
