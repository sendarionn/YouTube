## タイトルの候補

1. 新書レーベルは何が違う？ 5万点超の出版データで検証（推奨）
2. 中公新書は本当に「歴史に強い」のか？ 新書137レーベルをデータで比較
3. 新書レーベルの地図：分野・著者・売れ方で比べてわかったこと

- 指示書の仮タイトル「5万冊超」は、数えたものが刊行点数（タイトル数）で冊数（部数）ではないため「5万点超」にした
- サムネイル（レーベルの地図）と同じ文は入れていない

## 概要欄

```
岩波新書、中公新書、新潮新書、ブルーバックス……。新書のレーベルには、それぞれのイメージが語られます。そのイメージは、実際の出版の記録にも表れているのでしょうか。

国立国会図書館の書誌データから、主な新書137シリーズ・57,170点を集め、2016〜2025年の76シリーズ・13,828点を中心に、分野・著者・売れ方・時代の変化を比べました。

▼ わかったこと
・一般向けのレーベルは、扱う分野（日本十進分類法）の割合がよく似ている。違いが表れるのは書き手と売れ方
・分野ではっきり違うのは、交通新聞社新書（運輸）、ヨベル新書（キリスト教）、ブルーバックス（自然科学）など、分野を絞ったレーベル
・「中公新書は歴史に強い」は、歴史の本の点数（年17点ほど、最多）と、一般向けの大きなレーベルの中での割合の両方で裏付けられた
・よく語られるイメージは、データで確かめられる範囲では多くが当たっていた。政治的な傾向や読みやすさは確かめられない

▼ チャプター

7:22 まとめ

▼ 調査の範囲と注意
・対象は国立国会図書館の書誌で確認できた主要な新書シリーズ137で、日本の新書のすべてではありません（採否の基準は下の資料）
・「点」は重版などをまとめた刊行点数（1タイトル＝1点）で、書店の棚や在庫の割合ではありません
・著者の職業は Wikidata で照合できた著者（全体の47%）の中での割合です
・ベストセラーは年間上位10点に入った回数で、販売部数ではありません
・本の中身・紙面・読みやすさは、実物を調べていないため扱っていません
```

## 投稿時に確認すること

- 合成音声（本人の声）：YouTube の「改変または合成されたコンテンツ」の開示が必要か（AGENTS.md「音声合成」）
- GitHub のリンク：リポジトリの公開状態と、push 後のパスが正しいか
- チャプターの時刻：最終の final.mp4 の尺（manifest.json）と合っているか
- note の URL：公開後に `{{NOTE_URL}}` を置き換える。note を作らない場合は行を削除
