# 調査・制作指示書：日本の中心はどこなのか？

受け取り：2026-10-25（ユーザーの指示「下記の指示書で進めつつ、音声はVoiceboxで一旦作って」とともに受領。原文は下記）

## 1. 企画概要

**仮タイトル：日本の中心はどこ？ あらゆる「中心」を集めてみた**

日本の「中心」と呼べる場所を、地理・人口・経済・交通・文化・歴史など、可能な限り多様な観点から収集・調査し、日本地図上に可視化する。

特定の仮説の検証や、唯一の正解を導くことは目的としない。

「中心」の定義によって場所がどのように変わるのかを、自由研究のように探索する企画とする。

最終的には、調査結果をインフォグラフィック中心のYouTube動画として公開することを想定する。

## 2. 企画方針

- **網羅性と多様性を優先する。** 最初から対象数を限定せず、見つかった「中心」を幅広く収集する。
- 有名な「日本のへそ」だけでなく、公開データを使って独自に算出できる中心も対象とする。
- 中心の定義を恣意的に限定しない。数学的な重心、最大集積地、交通網の中心、歴史的中心などを含める。
- 特定の地域が中心になるという仮説を先に立てない。
- 調査結果に応じて興味深い発見を抽出するが、結論を無理に作らない。
- 計算の精度、データの信頼性、指標の意味を明確にする。

## 4. 「中心」の定義と分類

異なる概念を混同しないよう、収集した中心を分類する。

1. **幾何学的中心**：国土の面積重心、外接範囲の中点など。
2. **分布の重心**：人口、GDP、施設数などを重みとして求めた中心。
3. **最大集積地**：対象が最も集中している都道府県・市町村。
4. **ネットワークの中心**：交通・物流・通信などの接続構造から求めた中心。
5. **アクセスの中心**：全国の対象地点への移動時間・距離などを最小化する場所。
6. **制度的・歴史的中心**：首都、政治拠点、歴史的な都など。
7. **象徴的・通称的中心**：「日本のへそ」など、自治体や団体が独自に定義・主張する場所。

必要に応じて分類を追加・修正する。

最大集積地と重心、単純な地理的中点と最適なアクセス地点などは、異なる指標として扱う。

## 5. 調査方法

### 5.1 既存の中心を収集する

国や自治体、研究機関などが公表している「日本の中心」を収集する。

情報源の優先順位は以下とする。

1. 国土地理院、総務省統計局、国土交通省などの公的機関
2. e-Stat、国土数値情報、国勢調査などの一次データ
3. 大学・研究機関の論文や公開資料
4. 業界団体・企業の統計
5. 報道、書籍、ブログ、地域情報サイトなど

二次資料で見つけた情報は、可能な限り一次資料まで遡って確認する。

### 5.2 独自に計算できる中心を探す

既存の「中心」が公表されていなくても、公開データから計算できるものを探す。

例：

- 都道府県別GDPから経済重心を求める。
- 全国の鉄道駅を対象に、ネットワーク上の中心となる駅を求める。
- 全国の市町村への人口加重平均移動時間が最も短い地点を求める。

これらは計算方法の候補であり、実行可能性をデータの入手状況に応じて判断する。

地理的重心の計算では、適切な座標系・面積計算方法を使用する。交通網については、単純な座標の平均とネットワーク上の中心性を区別する。

### 5.3 集計単位・対象範囲を整理する

指標ごとに以下を記録する。

- 全国、都道府県、市町村、地点のどの単位で集計したか
- 使用データの対象年
- 離島や海域を含むか
- 算出地点が陸上・海上のどちらに位置するか
- データ欠損と推計の有無
- 行政区域・代表座標・重み付けの取り扱い

都道府県や市町村単位でしか集計できない場合は、地点単位の結果と区別する。

## 6. データの整理

収集した中心を、再利用可能なCSVまたはJSONとして保存する。

最低限、以下の項目を管理する。

| 項目 | 内容 |
|---|---|
| ID | 一意の識別子 |
| 名称 | 人口重心、GDP重心など |
| 分野 | 地理、人口、経済など |
| 中心の定義 | 何をもって中心とするか |
| 分類 | 重心、最大集積地、ネットワークなど |
| 場所 | 都道府県、市町村、地点名 |
| 緯度・経度 | 特定できる場合に記録 |
| 対象年 | 統計や調査の基準年 |
| 算出方法 | 公表値、独自計算、推定など |
| 情報源 | URL、資料名、発行元 |
| 信頼性 | 根拠の確かさと制約 |
| 備考 | 特徴、注意点、補足 |

情報が不明な場合は推測で埋めず、欠損として記録する。

個々の中心について、元データと計算過程を追跡できるようにする。

## 7. 分析・可視化

収集結果を用いて、以下の可視化を検討する。

**基本となる可視化**

- 日本地図上に中心点をプロットする。
- 分野ごとに色や記号を変えて表示する。
- 地点を選択すると、中心の名称・定義・出典が分かるようにする。
- 全件表示と分野別表示を切り替えられるようにする。

**追加の分析候補**

- 中心点が集中する地域を調べる。
- 分野ごとの分布の違いを比較する。
- 時系列データがある中心について、移動の軌跡を表示する。
- 定義が似ているのに離れた場所になる例を探す。
- 一般的に「中心」と呼ばれる場所と、定量的な中心の違いを整理する。

地図上の点が多い地域を機械的に「真の日本の中心」と判定しない。指標の選び方によって点の数が変わるため、単純な多数決は行わない。

## 8. 調査結果に応じた構成検討

調査終了後、結果を見て動画の構成を提案する。

基本形は以下とする。

1. 「日本の中心はどこ？」という問いから始める。
2. さまざまな定義の中心を紹介する。
3. 地図上に中心点を次々と追加する。
4. 特徴的な中心や、予想外の場所にある中心を紹介する。
5. 最後にすべての地点を俯瞰する。

特定の中心への集中が見られれば紹介し、分布がばらばらであればその違いを紹介する。

いずれの場合も、無理に総合的な結論やランキングを作らない。

動画はインフォグラフィックや地図、アニメーションを中心とし、文字情報を過剰に表示しない。また、音声のみでも大まかな内容を理解できる構成とする。

## 9. 今回の作業範囲と成果物

**今回は第1段階の調査・整理・分析・コンセプト提案までを実施する。**

成果物は以下とする。

1. **中心一覧データ**：収集した中心の名称、所在地、分類、定義、出典をまとめたCSV/JSON
2. **調査レポート**：分野別の調査結果と主な発見
3. **方法論資料**：データの取得方法、中心の算出方法、制約
4. **地図資料**：中心点を一覧できる地図。可能であればHTMLのインタラクティブマップ
5. **未解決事項一覧**：データ不足、未計算、信頼性が低い項目と、その理由
6. **動画構成の提案**：実際の調査結果から見つけた有望な見せ方と、取り上げる中心の選定案

中心の収集数に固定の上限や下限は設けない。十分に探索したうえで、追加調査の費用対効果が低下した時点で区切り、その判断理由を報告する。

新しい分野の発見を優先し、同じ内容の言い換えや、根拠の乏しい候補による件数の水増しは避ける。

## 10. 品質確認・停止条件

- 各中心の定義と出典が確認できること。
- 公表値・計算値・推定値・象徴的な呼称を区別していること。
- 使用した統計の対象年を明示していること。
- 独自計算は再現できること。
- 算出不能な項目について、その原因と必要なデータを整理していること。
- 海上など、自治体に帰属しない中心点を無理に自治体へ割り当てないこと。
- 未確認の事実や計算結果を創作しないこと。
- 動画で紹介する際の価値と、科学的に主張できる範囲を区別すること。

調査対象の大部分で信頼できるデータが得られない場合は、代替案と調査の限界を報告する。
