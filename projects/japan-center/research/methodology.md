## 座標系と重心の式

- 座標は経度・緯度（JGD2000／JGD2011 と WGS84 の差は全国規模の比較では無視できる。最大でも数 m）
- **重心の式は統計局の人口重心と同じ**にした（統計トピックス No.135「人口重心の算出方法について」）
  - 経度：Σ wᵢ xᵢ cos(yᵢ) ／ Σ wᵢ cos(yᵢ)、緯度：Σ wᵢ yᵢ ／ Σ wᵢ
  - 理由：公表値の人口重心と同じ基準で、ほかの重心と比べられるようにするため
  - 確認：統計局の都道府県別人口重心と2020年の人口から全国の人口重心を計算すると、公表値との差は 0.6 m（tests/test_centers.py）
- 定義による差の確認として、地点を地球の中心からの3次元ベクトルにした**球面上の重心**も計算し、差を `alt_km` に記録した
  - 差は 3.0〜13.0 km（中央値 5.5 km）。全国の人口重心では 5.4 km 北にずれる
  - 動画で「何 km 移動した」など数 km の差を扱う場合は、この定義の違いより小さい差に意味を持たせない
- 距離は GRS80 楕円体の測地線距離（pyproj）
- 面積は国土を正積図法（ランベルト正積方位図法、中心 北緯36度・東経137度）上の1km 四方の格子で数えた

## 代表点（どこに重みを置くか）

| 集計単位 | 代表点 | 注意 |
| --- | --- | --- |
| 市区町村（指定都市は区） | 統計局が公表した2020年の市区町村の人口重心 | 森林・耕地のように土地に結びつく量も人口重心に置くため、山間部の多い市町村では実際の分布より人の住む側にずれる |
| 都道府県 | 統計局が公表した2020年の都道府県の人口重心 | 1県の値が1点に集まる。北海道の漁獲量や農業産出額は札幌付近の1点に置かれる |
| 地点 | 座標そのもの（球場は住所の代表点、震央は USGS の座標） | 住所の代表点は町丁目・番地の位置で、施設の正確な位置ではない |

- 市区町村別の値がある指標は市区町村別を使った（製造品出荷額、小売販売額、事業所、従業者、耕地、森林、図書館、病院、病床、医師）
- 指定都市は区の値を使い、市の合計は使わない（`weighted_centers.leaf_units`）
- 2024年に区を再編した浜松市は、新しい区に2020年の人口重心がないため、市の合計の点に置いた。2025年の人口は2020年の区の人口の比で割り振った
- 2020年の人口が0の福島県双葉町は人口重心がないため除いた（2025年の人口 211 人分が推計から抜ける）

## 指標ごとの対象年

指標ごとに、地域の値が揃う最新の年（年・年度の値。月の値は使わない）を自動で選んだ。年は `data/indicators.csv` の time 列と `centers.csv` の year 列
主なもの：県内総生産 2022年度、製造品出荷額 2023年、小売販売額 2020年、事業所・従業者 2021年（経済センサス）、農業産出額 2023年、耕地 2024年、森林 2020年（農林業センサス）、海面漁業漁獲量 2023年、発電・電力需要 2023年度、延べ宿泊者数 2025年、大学数 2026年、大学学生数 2024年、病院・病床 2023年、医師 2022年、重要文化財 2025年

- 延べ宿泊者数の2025年は宿泊旅行統計調査の年の値。速報か確定かは API の値から判別していない（未確認）
- 指標の年が揃っていないため、指標どうしの比較は「同じ時点の比較」ではない

## 幾何学的中心

| ID | 方法 |
| --- | --- |
| area_all／area_excl_nt／area_main4 | 陸地の1km 格子（378,023 個 ≒ 378,023 km²。公表の国土面積 377,976 km² に近い）を同じ重みで数えた重心。北方領土の6村（地球地図日本の行政コード 01695〜01700）を除く版と、主要4島だけの版を作った |
| bbox_mid | 国土地理院の東西南北端（南鳥島・与那国島・択捉島・沖ノ鳥島）の経度と緯度の中間 |
| bbox_mid_main4 | 主要4島の陸地の東西南北端の中間 |
| coastline | 市区町村の面を島ごとに合わせ、島の外周（1,110 島）を線分の長さで重み付けした重心。海岸線の総延長は 26,950 km（1:100万の地図による。公表値より短い） |
| farthest_from_sea | 島ごとに、500m→100m の格子で、島の外周までの距離が最大の点を探した（到達不能極）。湖は海として扱わない |
| soya_sata_mid | 主要4島の最北端と最南端（地図上の宗谷岬・佐多岬）を結ぶ測地線の中点。渋川市の説明の検証用 |

- 地球地図日本は1:100万のため、小さな島や細かい海岸線は省略されている。面積重心への影響は小さいが、海岸線の長さは縮尺で大きく変わる

## ネットワーク・アクセスの中心

- 鉄道：線路の区間の端点を節点、区間を辺にしたグラフ（節点 20,621、辺 33,353）。同じ駅グループ（N02_005g）は乗り換えできるものとして結んだ
  - 本州・北海道・九州・四国がつながった最大の連結成分（駅グループ 8,421）だけを使う。沖縄のモノレールなどは含まれない
  - 鉄道網の中心：全駅グループへの線路上の距離の平均が最小の駅
  - 鉄道で全住民に最も近い駅：市区町村の人口を、人口重心に最も近い駅に割り当て、線路上の距離の人口加重平均が最小の駅
  - **所要時間ではなく距離**。新幹線と在来線の速さ、本数、乗り換え時間は考えていない
- 高速道路：地球地図日本の national motorway（rtt=16、2016年版）。北海道の高速道路は本州とつながらないため、最大の連結成分（本州・九州・四国）だけを使う
- 全住民への直線距離が最も短い地点：市区町村の人口重心と人口から、測地線距離の人口加重和が最小の点（Weiszfeld 法、幾何中央値）

## 分布の重心の補足

- 国勢調査の産業別就業者は**常住地**（住んでいる場所）。経済センサスの従業者は**従業地**（事業所の場所）
- 外国人住民は国勢調査の外国人人口
- 地震：USGS のカタログで、1996〜2025年の M5.0 以上、北緯19〜48度・東経120〜157度の範囲から、震央が陸地から200km 以内の 4,231 回。範囲と200km の基準は独自の設定で、変えると重心も変わる
- プロ野球：NPB の住所を国土地理院の住所検索で座標にした。エスコンフィールド HOKKAIDO の住所（北広島市Fビレッジ）は住所検索にないため、北広島市の代表点を使った

## 陸上・海上の判定

- 国土地理院の逆ジオコーダーで市区町村が返らない点を「海上」とした
- 地球地図日本の陸地の面でも判定し、結果が食い違う点はなかった（build_centers.py が食い違いを land 列に記録する）
- 海上の点は都道府県・市区町村に割り当てず、最寄りの陸地までの距離（1:100万の陸地による概算）だけを記録した

## カバレッジと調査の区切り

- 指示書3章の18分野のうち、データから点を求められなかった分野は「通信・情報（データセンター、通信ネットワーク）」の一部と「文化・芸術（出版・映画・音楽産業、伝統文化）」の一部。理由と必要なデータは unresolved.md
- 調査を区切った理由
  - 統計ダッシュボードで都道府県・市区町村別に取れる指標を、指示書の分野ごとに1〜5指標ずつ取った。同じ分野の指標を増やしても、人口や経済の重心と数十 km 以内の点が増えるだけで、新しい発見になりにくい（analysis.md「分野ごとの広がり」）
  - 残りの分野は、公開データがない（データセンター）か、定義そのものを作る必要がある（伝統文化の中心）もので、追加の費用に比べて得られる確かさが低い
- 自治体の主張は、全国へそのまち協議会の加盟9市町村のうち「日本」の中心を名乗る4市と、辰野町を収録した。NHK の番組が平均した28自治体の一覧は見つからなかった

## 再実行

```sh
cd projects/japan-center/research/scripts
PY=../../../../.venv/bin/python
$PY municipalities.py      # 国勢調査と人口重心 → data/municipalities.csv
$PY fetch_dashboard.py     # 統計ダッシュボード → data/indicators.csv（応答は cache/japan-center/dash/）
$PY geometry_centers.py    # 幾何学的中心
$PY weighted_centers.py    # 分布の重心・アクセスの中心（直線）
$PY network_centers.py     # 鉄道網・高速道路網
$PY other_centers.py       # プロ野球・地震・都道府県・渋川市の検証・人口重心の推移
$PY build_centers.py       # 一覧（centers.csv / centers.json）と所在地
$PY analyze.py > ../data/analysis_output.txt
$PY ../charts/map.py       # 地図 → output/japan-center/research/centers_map.html
cd ../../../.. && .venv/bin/python -m pytest -q projects/japan-center/research/tests
```

- 必要なライブラリ：pandas、numpy、shapely、pyproj、pyshp、scipy、requests、openpyxl、pypdf（.venv に追加した）
- 入力ファイルの取得元は sources.md。cache/japan-center/ に保存した元データを使う
  - src/：統計局の xlsx・PDF、e-Stat の xlsx
  - gm/：地球地図日本（gm-jpn-all_u_2_2.zip）
  - ksj/：国土数値情報 N02-24
  - dash/：統計ダッシュボードの応答（--refresh で取り直す）
  - gsi/：国土地理院 API の応答
  - npb/：NPB の球場の JSON
  - usgs_m5_1996_2025.csv：USGS の応答
- API の値が更新されると、対象年が新しくなり結果が変わる。研究版を承認したら cache/japan-center/ をバックアップする
