## 信頼性が低い・確認が必要

| 項目 | 内容 |
| --- | --- |
| 航空貨物の重心 | 統計ダッシュボードに指標の定義がない。成田空港のある千葉県が上位にないため国内線の貨物とみられるが、推測。動画では使わない |
| 重要文化財の重心 | 国立博物館などが所有する美術工芸品が多い東京都が全国の21%を占める。「文化財の重心」としては、所有者の所在地に左右されることを注記する。建造物だけの集計は未実施 |
| 銀行預金の重心 | 預金は店舗の所在地で集計され、預金者の住所ではない |
| 延べ宿泊者数の2025年の値 | 速報値か確定値かを確認していない |
| 歴代の都・幕府 | 年代は通説で、一次資料（史跡の指定資料）を確認していない。座標は町名・区の代表点 |
| 渋川市の地理的な根拠 | 「円で結んだ中心」の意味が確認できない。解釈によって結果が変わる |
| チコちゃんポイントの距離 | 町の説明（ゼロポイントから約10m）と公表座標の差（約160m）が合わない。座標の丸めによる可能性がある |
| 地震の重心 | USGS のカタログで、気象庁の一元化震源とは一致しない。範囲（陸地から200km）は独自の設定 |
| 高速道路網 | 地球地図日本（2016年版）。その後に開通した区間を含まない |
| 2025年の人口重心 | 推計。統計局の公表（2020年分は2023年1月公表）を待って差し替える |
| エスコンフィールド HOKKAIDO の位置 | 住所検索にないため北広島市の代表点 |
