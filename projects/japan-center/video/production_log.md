## FCPXML の構成（編集できる範囲）

| 要素 | 内容 |
| --- | --- |
| 基本ストーリーライン | シーンごとの映像クリップ19本（S001〜S019）。並べ替え・差し替えができる |
| レーン -1 | ナレーション（シーンごとに区切って各クリップに接続、ロール Dialogue） |
| レーン -2 | BGM（ダッキング済みの1本、ロール Music） |
| レーン 1 | 字幕クリップ78本（SRT ロール、日本語）。シーンに接続しているため、シーンを動かすと一緒に動く |
| マーカー | 各シーンの先頭に「S001 導入」などのマーカー |

- 地図・図解の中身は Final Cut Pro では編集できない。変更は scenes.py を直して、そのシーンだけ書き出し直す（`build.py export --only N`）
- ナレーションの修正は scenes.py の Line を直すと、変更した文だけ再合成される（音声はキャッシュ）
- 実写の挿入候補はない（撮影リスト shot-list.md は「撮影候補なし」）。地図の上に実写を重ねる場合は、レーン 1 以上に置く
- 字幕を FCPXML に入れる機能は、共通ツールに既定では無効の引数として追加した（tools/fcpxml の captions、export の fcpxml_captions）。ほかの動画の出力は変わらない

## 音声

- VOICEVOX ENGINE 0.25.2（models/voicevox/engine_ditto、ローカル）、春日部つむぎ（speaker 8）、話速 1.1・抑揚 1.1（tools/voice/voices.json の voicevox）
- 制作指示書が標準とした voicevox を使った。本人の声（self）には変えていない
- 読みの修正（scenes.py の YOMI）：「値」が「ネ」と読まれたため「あたい」、「早川町」をひらがなにすると「山梨県は／やかわちょう」と区切られたためカタカナ、ほかに七宗町（ひちそうちょう）・関市・辰野町（たつのまち）など
- エンジンが返す読み（output/…/lines.json の reading）を全78文で確認した
- 書き起こし（faster-whisper medium、ローカル）で読みの差が 0.1 以上の6文は、エンジンの読みでは正しく、書き起こしの誤り（太平洋→大平洋、耕地→工地、分布→文部、東経→統計 など）だった

## 品質確認の結果

| 項目 | 結果 |
| --- | --- |
| final.mp4 とシーン映像のフレーム一致（30,550 フレーム） | 一致 |
| FCPXML の DTD 検証（Final Cut Pro 同梱の FCPXMLv1_13.dtd）と素材の存在 | 問題なし |
| 音声ファイルの長さ | 一致 |
| 場面転換以外の急な画面の変化（縮小画像のフレーム差 > 6） | 0 |
| 動いている区間の停止（カクつき） | 0 |
| 字幕と台本 | SRT 78文が台本と一致。FCPXML の字幕クリップ78本が SRT と一致 |
| ラウドネス（final.mp4） | 統合 −17.2 LUFS、トゥルーピーク −1.5 dBTP、LRA 4.1 |
| ナレーションと BGM の差（発話中） | 16.2 dB |
| 研究資料との数値の照合 | scenes.py の load_numbers で、ナレーションの数値（97個、15km、29km、2km、115km、48個・28個、15個、27群・14群、15分野・10分野、8割、2人、1,100人など）を研究データと照合（assert） |
| 画面の確認 | 全場面の各文の静止画（97枚）と、拡大・図解の連続フレームを画像で確認 |

- 最初の書き出しで静止が長い区間（最長16秒）が5か所あったため、内容に沿った動き（候補の提示、全国への引き、重みの円と支点、人口の円、言葉に合わせた強調）を加えて書き出し直した。残る静止は最長7.6秒（図表や地図を読む時間）
- BGM の音量の急な変化として検出された箇所は、曲の休符の後の打鍵（曲そのものの強弱）だった

## 自律的に判断したこと

- 字幕は画面に焼き込まず、SRT と FCPXML の字幕クリップで出した（DESIGN.md「字幕・注記・出典」。画面の文字を最小限にするため）
- 「重心とは」の図解を地図の場面より前に置いた（後半の意外な重心の説明に使うため）
- 「岐阜に集まるのはなぜか」の検証の場面を加え、件数だけで岐阜を中心と言わない構成にした（追加検証①）
- 情報通信業の重心は、首都圏とそれ以外の重みの円と支点で図解した（追加検証②）。「中心地」とは言っていない
- 最大集積地は地域の塗り、標準時子午線は破線の経線、ほかは点で描き分けた
- 歴代の都の年代は、公的機関の資料で確認した3つだけを示した
- 渋川市の根拠の検証と航空貨物の重心は扱わなかった
- 国土の形のマス目（場面4）は説明用の 40km の格子で、計算は 1km の格子（画面の注記に記載）
- 冒頭の「地図の真ん中？」「人が多く住むあたり？」「首都の東京？」の灰色の印は、問いの例示で、データの点ではない（形と色を中心点の記号と変えた）

- 2025年の人口重心は推計。統計局の公表が出たら差し替える
