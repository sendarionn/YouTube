# 調査方法

企画：成功した起業家は結局エリートなのか
作業開始：2026-10-17

## 母集団

- 出典：JPX「新規上場会社情報」
  - 2022〜2025年はJPXの現行ページを使う
  - 2016〜2021年はJPXのページから削除済みのため、Wayback Machineに保存されたJPXのページを使う（保存時点は `scripts/fetch_jpx.py` に記載）
- 期間：上場日が2016-01-01〜2025-12-31
- 市場：東証の一般市場すべて（マザーズ、JASDAQ、一部、二部、プライム、スタンダード、グロース）
  - TOKYO PRO Market は対象外（JPXの一覧に含まれない）
  - 地方取引所の単独上場は対象外（追加調査の候補）
- 件数：995件（テクニカル上場を含む）

## 除外と分類

テクニカル上場（JPXの一覧で会社名に「*」）は除外する（92件）

残る903件を、Iの部（上場申請のための有価証券報告書）の沿革と役員略歴を読んで次の型に分類する（`data/screening.csv` の `type`）

| 型 | 定義 | 創業者分析 |
| --- | --- | --- |
| IND | 個人が創業した会社（前身の個人事業・前身会社を含む） | 対象 |
| SPIN | 大企業の社内事業・子会社から、創業者個人がMBO等で独立した会社 | 対象（区別して集計） |
| UNIV | 大学・公的研究機関の研究成果を事業化した会社 | 対象（区別して集計） |
| CORP | 大企業の子会社・合弁・分社・民営化として設立された会社 | 対象外 |
| HOLD | PE等が設立した持株会社で、事業会社の創業者を特定できないもの | 保留 |
| RELIST | 過去に上場していた会社の再上場、他の取引所からの上場 | 対象外 |
| FOREIGN | 外国会社 | 対象外 |
| UNK / NOP1 | 資料不足で判定できないもの | 保留 |

判定の根拠は `founder_source` に記録する

- P1-officer：Iの部の役員略歴に「当社設立」等の記載
- P1-history：Iの部の沿革・前文に創業者の記載
- MIRROR-*：最新の有価証券報告書（転載ページ）の沿革・役員略歴
- EXT：外部資料での確認が必要

## 創業年と経過年数

- 創業年月（`origin_ym`）は、現在の事業の起点を指す
  - 法人設立前の個人事業や前身会社が沿革に「前身」「創業」として記載される場合はそれを起点とする
  - PE等による持株会社化・合併で法人格が新しくなった場合は、事業会社の設立を起点とする
- 経過年数 = 上場年 − 創業年
- 中心的な分析対象：IND・SPIN・UNIVのうち経過年数20年以内
- 比較：10年以内、期間制限なし

## 創業者

- 現任社長ではなく、実際に創業した人物を記録する
- 共同創業者は、沿革または役員略歴で「当社設立」「共同創業」等が確認できる人物を全員記録する
- 確認できない場合は「?」とし、推測で補わない
- 集計は人数ベースと企業ベースを分ける

## 職歴（`data/founders_career.csv`）

出典はIの部の役員略歴（上場時点）。Iの部がない場合は最新の有価証券報告書の役員略歴を使い、`career_source` に記録する

- 創業前の経歴：略歴のうち「当社」の記載が初めて現れる前の項目
- 初職：創業前の経歴で最初の「入社・入行・入所・入省・入職」等
- 創業直前の勤務先：創業前の経歴で最後の勤務先
- 職歴年数：創業年 − 初職の年
- 連続起業：創業前の経歴に別会社の「設立・創業・開業」がある
- 学生起業：創業前に勤務歴がなく、創業時25歳以下
- 勤務先の分類：勤務先名に含まれる語の辞書で判定する（`scripts/classify_careers.py` の `CATS`）
  - コンサルティング、金融、会計・法律、総合商社、ネット大手（メガベンチャー）、外資系IT、国内大手メーカー・インフラ等、官公庁・研究機関・大学、医療
  - 一人が複数の分類に該当してよい
- 大手組織での勤務経験（`large_org`）：上記のうち、コンサル・金融・総合商社・ネット大手・外資系IT・国内大手のいずれかに該当
  - 勤務当時の従業員数や上場状況は個別に検証していない（limitations.md 参照）
  - 現在の会社規模から過去の規模を推測していない。辞書は社名で判定し、規模の推定は行わない

## 学歴（`data/evidence.csv`）

学歴はIの部・有価証券報告書にほとんど記載がない（試験調査で69人中5人）ため、外部資料を使う

1. Web検索で候補となる出典を探す（1人あたり原則1〜2回）
2. 出典ページを取得し、原文に該当する記述があることを確認する（`scripts/quote.py`, `batch_quote.py`）
3. 原文の該当箇所を `quote` に記録する
4. 確認状態を記録する
   - verified：原文で一致を確認
   - partial：在学中の起業など、卒業・修了が明記されていない
   - unverified：検索結果の要約のみで、原文を取得できなかった
   - 検索結果の要約は分析に使わない。要約と原文が食い違った例があった（高橋飛翔氏：要約は中央大学、公式サイトの原文は東京大学法学部卒業）

学歴の区分

- 大学院修了、大学卒業、大学中退・在学中に起業（卒業未確認）、短大・高専・専門学校等、高校卒業、不明
- 海外大学は国内と区別して記録する
- 判明者だけの集計は有名な創業者に偏るため、無作為標本も調べる
  - 創業20年以内の対象企業で氏名が分かった創業者474人から、乱数で100人を抽出（`scripts/edu_sample.py`、シード20261017、`data/edu_sample.csv`）
  - 標本の全員について、検索1〜2回で学歴の出典を探す
  - 「大学卒業後」のように大学名がない記述も、学歴の区分には使う（大学名は不明として扱う）
- 「エリート大学」を一つの定義に固定しない。分析では次の複数の基準を並べる
  - 大学名別の人数
  - 国公立・私立・海外
  - 旧帝国大学＋一橋・東京工業（現東京科学）・神戸、早稲田・慶應の各グループ
  - 大学別の卒業者数に対する出現倍率（比較対象の項を参照）

## 比較対象

| 比較集団 | 出典 | 注意点 |
| --- | --- | --- |
| 新規開業者 | 日本政策金融公庫「2025年度新規開業実態調査」（2025-12-05公表）。経年比較に2024年度版も使う | 公庫の融資先（小規模事業が中心）。上場企業の創業者とは事業規模が大きく異なる。勤務経験は調査票の自己申告で、役員略歴とは範囲が異なる |
| 同世代の大学進学率 | 国立社会保障・人口問題研究所「人口統計資料集2026」表11-3（原典：文部科学省「学校基本調査」） | 進学率であり卒業率ではない。過年度卒を含む。創業者の生年の中央値は1976年（18歳時は1994年）のため、1990〜2000年の値を使う |
