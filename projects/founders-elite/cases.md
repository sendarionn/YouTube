# 創業者の事例：会社員時代の経験と起業の理由

確認日：2026-10-17
動画「上場した創業者は、何歳で起業したのか」の事例の章で使う

## 選び方

- 条件
  - 今回の調査対象（創業から上場まで20年以内、創業者の氏名と職歴が判明した419人）に含まれる
  - 起業のきっかけと事業を選んだ理由を、本人がインタビューや寄稿で語っている
- 指示書の候補3人のうち、マネーフォワード（辻庸介氏）は差し替えた
  - 上場申請書類の沿革・役員略歴に「設立」の記載がなく、調査データでは創業者を特定できていない（`data/screening.csv` で「?」）
  - 統計に含まれない人を「統計の傾向を具体化する事例」にすると整合しないため
- 代わりにビズリーチ（上場時の社名はビジョナル）の南壮一郎氏を選んだ。本人が起業の経緯を詳しく語っている

| 人物 | 創業時の年齢（創業年−生年） | 初職から創業まで | 大手組織の勤務経験 |
| --- | --- | --- | --- |
| 寺田親弘 | 31歳（下から44.6%） | 8年（下から37.2%） | あり（総合商社） |
| 佐々木大輔 | 32歳（下から49.6%） | 8年（下から37.2%） | あり（金融・外資系IT・国内大手の分類に該当） |
| 南壮一郎 | 31歳（下から44.6%） | 8年（下から37.2%） | あり（金融・ネット大手の分類に該当） |
| 全体 | 中央値33歳、四分位範囲28〜38歳 | 中央値10年、四分位範囲5〜14年 | 54.7% |

- 3人とも中央値に近いが、大手組織の経験がある側（54.7%）に入る
- 有名な創業者ほど経歴と動機が公開されているため、事例の選び方には偏りがある。無作為に選んだ例ではない

## ① 寺田親弘（Sansan）

| 年月 | できごと | 出典 |
| --- | --- | --- |
| 1999年4月 | 三井物産に入社 | Iの部 役員略歴 |
| 2001年5月 | Mitsui Comtek社（シリコンバレー）勤務 | Iの部 役員略歴 |
| 2006年2月 | 三井物産セキュアディレクションに出向、経営管理部長 | Iの部 役員略歴 |
| 2007年6月 | Sansan（設立時の社名は三三）を設立、代表取締役社長 | Iの部 役員略歴・沿革 |
| 2019年6月 | 東証マザーズに上場 | JPX |

- 会社員時代の仕事：シリコンバレーでのベンチャー企業の日本向けビジネス展開支援、社内ベンチャーの立ち上げ、子会社の経営管理（EYのプロフィール、Forbes JAPAN）
- 起業の動機（本人）
  - 「父親が事業をしていたこともあり、普通のサラリーマンとして生きていこうということもなく、元々起業家志向は強かった。学生でそのまま起業することは考えていなかったので、まず修行の場として三井物産を選び」（週刊東洋経済）
  - 新卒で入社する際も起業したいと公言していた。30歳のとき会社を辞めた。具体的な計画があったわけではない（Forbes JAPAN、記者の地の文）
- 事業を選んだ理由（本人）
  - 「日々、たくさんの名刺をもらいますが、その管理は非常に煩わしい。それをデータベース化できないかと、ずっと考えていました。僕自身に通底する考え方として、身近で手触り感のある課題からしかビジネスを着想できない」（Forbes JAPAN）
  - 「どうせやるなら世の中の困りごとを解決したいと思い、目を付けたのが名刺だった。『あの名刺どこに行った？』というリアルな悩みがもともとあった」（週刊東洋経済）
- 確認できなかったこと
  - シリコンバレー駐在が起業や名刺事業の着想につながった、という本人の発言は見つからなかった。動画では経歴として紹介し、動機とは結びつけない
  - 週刊東洋経済の記事は「6年間の勤務を経て起業」とするが、役員略歴では1999年4月入社・2007年6月設立。動画では年数を言わない

## ② 佐々木大輔（freee）

| 年月 | できごと | 出典 |
| --- | --- | --- |
| 2004年4月 | 博報堂に入社 | 有価証券報告書 役員の状況 |
| 2006年7月 | CLSAキャピタルパートナーズジャパン（投資ファンド）に入社 | 同 |
| 2007年5月 | ALBERT に入社（本人は「CFOをやっていた」と説明） | 同、flier |
| 2008年5月 | グーグルに入社 | 同 |
| 2012年7月 | freee（設立時の社名は CFO）を設立、代表取締役CEO | 同 |
| 2019年12月 | 東証マザーズに上場 | JPX |

- 会社員時代の仕事：グーグルでアジア・パシフィック地域の中小企業向けマーケティングを担当（本人、flier）
- 起業の経緯（本人、flier「freee誕生秘話」）
  - 「グーグルでアジア・パシフィック地域における中小企業向けのマーケティングを担当していました。この仕事に携わっているうちに、日本の中小企業は全般的にテクノロジーの活用が遅れている、という危機感を覚えるようになったんです」
  - 「世の中の中小企業に普遍的な影響をもたらせるようなプロダクトやサービスはないのかということを考えていました」
  - 「グーグルに入社する前、ALBERTというスタートアップでCFOをやっていたのですが、そのとき経理担当の人が一日中入力作業をやっていたんですね。…使っていた会計ソフトがボトルネックになっていることが分かりました」
  - 「調べてみた結果、この業界には何のイノベーションも起きていませんでした。…誰も挑戦していなかったんです」
  - 「やらない理由を聞かされるうちに、やる前に挫折した人が多いのではないか。それなら、まずやってみるべきだ」と考え、自分でプログラミングを始めた
- 補足：共同創業者の横路隆氏（ソニー出身）も、実家の自営業で会計処理を手伝った経験があった（@IT の記事。動画では扱わない）

## ③ 南壮一郎（ビズリーチ、上場時はビジョナル）

| 年月 | できごと | 出典 |
| --- | --- | --- |
| 1999年7月 | モルガン・スタンレー証券に入社 | Iの部 役員略歴 |
| 2001年1月 | パシフィック・センチュリー・サイバーワークス・ジャパン（投資会社）に入社 | 同 |
| 2004年9月 | 楽天野球団（楽天イーグルス）の創業メンバーに | 同、本人インタビュー |
| 2007年8月 | ビズリーチを設立、代表取締役社長 | 同、沿革 |
| 2009年4月 | 転職サイト「BizReach」を開始 | Iの部 沿革 |
| 2021年4月 | 持株会社ビジョナルとして東証マザーズに上場 | JPX |

- 球団を辞めた経緯（本人、ニュースイッチ）
  - 当時31歳。球団社長から「お前は30代をどう過ごすんだ？」と問われ、外の世界で学ぶよう背中を押された
- 起業の経緯（本人、ニュースイッチ）
  - 「辞めたことと起業とは直接関係ありません。僕は楽天という会社にいたけどインターネット事業をやっていなかった」
  - 「2年間はインターネット事業をやってみようと自分を正当化したんです。ちょうど日本の転職活動の非効率さを自分の体験から感じていて、やっぱりそこからは直感ですね」
  - 「楽天が小売業でやったＥコマース（電子商取引）によってすべて可視化される効果と、ビズリーチは似ていると思います」「会社を作った当初はまだぼんやりとしていたんですが、すべてつながったんです」
- 事業を選んだ理由（本人の寄稿、ライフハッカー）
  - 「このサービスは、私が転職活動をしていた際に『なぜ、求職者はすべての選択肢と可能性からキャリアを選べないのか』と感じた不便さをきっかけとして、2009年に立ち上げました」

## 共通点と相違点（制作側の整理）

本人の発言そのものではなく、上の発言を並べて制作側が整理したもの

| | 寺田 | 佐々木 | 南 |
| --- | --- | --- | --- |
| 起業の意思 | 学生時代から（会社員は修行） | 仕事の中で問題に気づき、作ることを決めた | 球団を辞めた後、インターネット事業をやると決めた |
| 事業のもとになった問題 | 名刺の管理の煩わしさ | 経理の入力作業、中小企業のIT活用の遅れ | 自分の転職活動の非効率さ |
| 問題に出会った場 | 会社員としての日常業務 | CFO・グーグルでの業務 | 自分の転職活動 |

- 共通点：3人とも、事業のテーマを自分が実際に困った、または見た問題から選んだと語っている
- 相違点：「起業が先、テーマが後」（寺田、南）と「問題が先、起業が後」（佐々木）で順番が違う
- 言えないこと：3人の事例から、会社員の経験が上場の原因だった、特定の会社で働くと有利だ、とは言えない
