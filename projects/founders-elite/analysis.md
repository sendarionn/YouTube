# 分析結果

対象：2016〜2025年に東証へ新規上場した会社のうち、個人創業・独立・大学発で、創業から上場まで20年以内の455社
創業者：氏名が分かった474人（職歴が分かった419人）
数値の出典（2026-10-17、初職年の抽出誤りを修正後に再集計）：`data/summary.json`、`data/breakdowns.json`（`scripts/analyze.py`、`scripts/breakdowns.py`）
グラフ：`output/founders-elite/charts/`

## 要点

- 創業時の年齢の中央値は33歳。公庫調査の新規開業者（平均43.9歳）より約10歳若い
- ただし学生起業は6.0%で、中央値で約10年の職歴を経てから創業している
- 職歴が分かった人の54.7%に、コンサル・金融・総合商社・ネット大手・外資系IT・国内大手のいずれかの勤務経験がある
- 学歴は公開情報で確認できない人が大半（無作為標本でも72%が不明）。確認できた人の多くは大卒以上で、大学名は東大・早慶・旧帝大に偏るが、この偏りは「学歴が語られる人」の偏りと区別できない

## 仮説A：成功した起業家は高学歴なのか

### 判明状況

| 集計 | 判明 | 分母 |
| --- | --- | --- |
| 20年以内の全創業者 | 87人 | 474人 |
| 無作為標本 | 28人 | 100人 |

### 最終学歴

| 区分 | 全創業者 | 無作為標本 |
| --- | --- | --- |
| 大学院修了 | 24 | 10 |
| 大学卒業 | 41 | 14 |
| 大学在籍・在学中起業（卒業未確認） | 14 | 2 |
| 大学中退 | 1 | 0 |
| 短大・高専・専門学校 | 3 | 0 |
| 高校卒業・大学進学なし | 4 | 2 |
| 不明 | 387 | 72 |

- 無作為標本で大学卒業以上が確認できたのは24人。全員を分母にすると下限24%、不明が全員大卒以上なら上限96%
- 判明者に限ると大学卒業以上は86%（24/28）
- 比較：創業者の生年の中央値は1976年。18歳になる1994年前後の大学進学率は、1995年で総数31.9%、男性40.5%（IPSS表11-3）
- 判明者の割合（86%）は同世代の進学率を大きく上回るが、判明の偏りがあるため「創業者の大卒率」としては使えない

### 判明の偏り

- 学歴が判明した人は、大手組織の勤務経験の割合が69.7%。判明しなかった人は60.4%（2026-10-21 訂正。旧記載60.5%は初職年の修正前の値。progress.md「訂正の記録」）
- 有名企業出身・有名企業の創業者ほど、インタビューや公式プロフィールで学歴が語られやすいと考えられる
- 「大学卒業後」とだけ書かれ、大学名が出ない記事も多い（標本で4人）

### 判断

- 「成功した起業家は高学歴」とも「学歴は関係ない」とも、このデータでは言えない
- 言えるのは「公開情報で学歴が確認できる創業者は少数で、その少数は東大・早慶などに偏っている」まで

## 仮説C：起業は一発逆転なのか

### 創業時の年齢（419人）

| 年齢 | 人数 | 割合 |
| --- | --- | --- |
| 25歳以下 | 47 | 11.2% |
| 26〜29歳 | 101 | 24.1% |
| 30〜34歳 | 93 | 22.2% |
| 35〜39歳 | 105 | 25.1% |
| 40〜49歳 | 59 | 14.1% |
| 50歳以上 | 14 | 3.3% |

- 中央値33歳、平均33.6歳

### 創業前の職歴

- 初職から創業までの年数の中央値は10年（初職の年が分かった366人）
  - 0年3人、1〜4年72人、5〜9年99人、10〜14年101人、15〜19年50人、20年以上41人
  - 初職は創業前の最初の「入社・入行・入所」等。自営・前の起業・研究職の「助手」などは初職に数えない
- 学生起業（勤務歴なし・25歳以下）6.0%（25人）
- 略歴に勤務先の記載がない人12.6%
- 連続起業（創業前に別会社を設立）19.8%

### 公庫の新規開業者との比較

| 項目 | IPO創業者（本調査） | 新規開業者（公庫2025年度） |
| --- | --- | --- |
| 創業時の年齢 | 中央値33歳・平均33.6歳 | 平均43.9歳 |
| 29歳以下の割合 | 35.3% | 7.0% |
| 勤務経験あり | 87.4%（略歴に勤務先の記載あり） | 97.6% |
| 勤務経験の年数 | 初職から創業まで中央値10年 | 平均21.1年・中央値20年 |
| 大学・大学院卒 | 不明（判明者は86%） | 35.9% |

- 公庫調査は融資先の小規模な開業が中心で、事業の種類と規模が大きく異なる
- 勤務経験の定義も異なる（limitations.md）
- この比較から「若く起業すると上場しやすい」とは言えない。上場を目指す事業は若い時期に始められる種類が多い可能性がある

### 判断

- 「職歴なしで若くして起業し、一発で成功」に当てはまる人は1割前後
- 多くは会社員として約10年働き、30代前半で創業している
- 一方で、一般の開業者と比べると約10歳若い。「大企業で定年近くまで勤めてから独立」とも違う

| 創業時年齢（中央値） | 33.5歳 | 33歳 | 32歳 |
| 大手組織の経験 | 59.5% | 54.7% | 51.0% |

## 結論に使える度合い

| 主張 | 根拠の強さ |
| --- | --- |
| 創業者の多くは約10年の職歴を経て30代前半で創業 | 強い（419人、Iの部の略歴） |
| 半数強に大手組織の勤務経験 | 中（辞書による分類） |
| 一般の開業者より約10歳若い | 中（集団と定義が異なる） |
| 学生起業・職歴なしは1割前後 | 中（略歴に載らない勤務がある） |
| 成功した起業家は高学歴 | 弱い（判明率が低く偏りがある） |
| 学歴が分かる創業者は東大・早慶に偏る | 強い（ただし「判明者」についての事実） |
