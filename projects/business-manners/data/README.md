# data/

| ファイル | 内容 | 出典・作り方 |
| --- | --- | --- |
| ndl_title_counts.csv | 題名に語を含む国立国会図書館所蔵資料の年別件数 | `scripts/count_titles.py`（NDLサーチ OpenSearch API） |
| ndl_airline_manner_titles.csv | 題名に「マナー」を含む資料のうち航空会社・CAを題名・著者・出版者に含むもの | `scripts/airline_titles.py` |
| ryokai_manner_books.csv | マナー本319冊の「了解」の扱い | 髙橋ほか（2018）表4。詳細は ryokai_manner_books.md |
| gokurou_dictionaries.csv | 国語辞典の「御苦労」項に上下関係の注記があるか | 倉持益子（2011）表1（『明海日本語』16, p.14）。○をY、×をNとした |
| bunka_h17_gokurou.csv | 仕事が終わったときに掛ける言葉（相手の職階別） | 文化庁 平成17年度「国語に関する世論調査」問5（2006年2〜3月、個別面接、有効回収2,107人） |
| en2025_survey.csv | ビジネスマナーの必要性と重要だと思うもの | エン株式会社『エン転職』ユーザーアンケート（2025年9月、インターネット、1,435名）。転職サイト利用者で無作為標本ではない |

- 数値はすべて出典の本文・図表と照合済み（2026-10-18）
- en2025 の「不要だと思うもの」は「必要ではない」と答えた約2%だけが対象のため収録していない
