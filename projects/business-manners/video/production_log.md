## 構成のファイル

| ファイル | 内容 |
| --- | --- |
| scenes.py | 台本（場面と文）と各場面の描画。数値は data/ の CSV から読み込み、論文の記載と合わなければ止まる |
| build.py | 台本・字幕・読みの確認表・静止画・MP4 の書き出し |
| qa.py | 完成動画の自動検証（形式、ラウドネス、無音、フレーム間の急な変化） |
| narration.md | 実際のナレーションと場面の時刻（build.py が生成） |

| claims.md | 出典対応表 |
| assets.md | 素材管理 |
| description.md | 概要欄の案（章の時刻、出典、クレジット） |
| build_info.json | 音声・BGM・アイコン・ミックス・ライブラリのバージョン（書き出し時に生成） |

## 再生成の手順

1. VOICEVOX ENGINE 0.25.2 を起動する（`models/voicevox/engine_ditto/run --host 127.0.0.1 --port 50021`。展開方法は projects/founders-elite/progress.md）
2. `projects/business-manners/video/` でリポジトリ直下の `.venv` の Python を使う
   - `python build.py script`：台本・字幕・読みの確認表
   - `python build.py frames [場面番号…]`：確認用の静止画（`output/business-manners/video/frames/`）
   - `python build.py render`：MP4 と build_info.json（60fps で約50分）
   - `python qa.py`：自動検証（`qa_report.json`）
3. アイコン集と BGM の原本がなければ、台帳の URL から取得し sha1 を照合する（`library/icons/`、`library/bgm/`）
4. テスト：リポジトリ直下で `python -m pytest tools/infographic/tests projects/business-manners/tests`

- 再生成時は保存済みの台本・データ・素材を使い、台本や BGM を選び直さない
- 制約：VOICEVOX のバージョンや辞書が変わると、音声と時刻が変わりうる。PyMuPDF のバージョンが変わるとアイコンの描画が僅かに変わりうる
